# Witness evaluation (S4b tracking; deterministic fusion, Muse off)

Generated by `coopx.eval.report` from the JSONL result files. No hand-edited numbers.

**Replay.** Causal: observers run SAM at 2 Hz from 3 s before each mined clip to 3 s
after it; detections enter only at their measured availability time (cached calls
replay their original latency). Roadside units publish real-LiDAR free space. Remote
packets cross the link into the ego's checker; ego cameras stay local. Fusion runs at
every 10 Hz frame on what has arrived.

**Scoring.** Precision is one-to-one against *all* labelled objects within the stated
radius of the ego; extra beliefs on an already-matched object are *duplicates* (one
object seen by several observers), beliefs outside the radius are *out of region*;
neither counts as a false hazard. Occluded recall counts only frames whose ego
visibility label is `occluded` (FOV alone is not occlusion). Lead time is first
warning to the ego's first labelled-visible frame; `n/a` = no warning or the ego
never sees the target in the window (censored, not success).

**Split.** `report` = mined clips (`data/scenes/scenes.json`). The user approved these report clips after camera-view review on 2026-11-04. This approves visual clip selection, not warning timing.
`tune` = S3 frame 000096: pedestrian 53 partly enters ego cam2 and is labelled
`insufficient_evidence`; it is not an occluded report clip. No parameters were tuned on report clips.
The UPS/pedestrian-110 example is an illustrative still (0.2 s roadside support),
excluded from clip timing claims. Missing later ego visibility remains censored.

**Modes.** `ego` own sensors only; `union` every admitted remote claim (absence claims
never delete a local detection); `geo` object-level geometric consensus inspired by
ROBOSAC/CAD (>=2 physical bodies within 1.5 m / 3 m and 300 ms; eligible range free
space contradicts), not a reproduction; `witness` authenticated-root assessment.
`replay_refreshed` is not caught by design: a fresh capture time with the attacker's
own valid signature passes freshness. `independent witnesses` follows EvidenceStore:
unanchored identities count zero; relays of one observation count once.

Main rows use SAM perception. `gt-oracle` places targets at ground truth when labelled
visible; it is a comparison, not a result.

## Tracking and decision-time prediction

IDs and signs a velocity estimate and its uncertainty. Model completions are processed in availability
order. Older positives remain evidence, while an older measurement cannot overwrite a newer position.
Only past captures enter a signed velocity estimate. Consumers predict
from capture to decision

checks use the original capture position and time. A refutation remains attached to later updates

### Parameters and provenance

Parameters come from operating bounds and non-target tuning data: two-second/four-interval fit at existing 2 Hz; four-second prediction cap from existing five-second TTL minus one-second guard; association gates are rounded above p95 on 75 non-target tuning pairs: image motion 2 box diagonals/s, Hellinger distance 0.7, pair cost 5.5; speed and acceleration values are conservative engineering operating bounds, checked on non-target pedestrians in the frame-000096 tuning replay.

The same parameters apply to both report clips. Speed limits (pedestrian 8, vehicle 60,
cyclist/unknown 20 m/s) are declared operating bounds, not claims of universal human/vehicle limits.
Association uses 3D uncertainty, box overlap and masked HSV histograms with global Hungarian
assignment and explicit unmatched detections; class, anchor and label must agree. Gates were
rounded above the 95th percentile of 75 non-target tuning pairs: two box diagonals per second,
0.7 Hellinger appearance distance and 5.5 combined cost. They are fixed across report clips.
Velocity uses a weighted least-squares fit over at most two seconds; position uncertainty supplies
measurement noise, fit residuals increase uncertainty, and velocity standard deviation has a 0.1 m/s floor.
The 1.5 m/s² acceleration process-noise assumption bounds confidence in the constant-velocity model;
uncertainty is not a wider scoring radius or a calibrated coverage guarantee.
There is no cross-camera appearance matching. Identity switches, sparse lift geometry, acceleration
and initial frames without a velocity estimate remain limitations. Prediction does not reduce model latency.
